# DotNest Support

This repository serves as the support site for [DotNest](https://dotnest.com/), the Orchard Core/Orchard 1 SaaS.

- [Create an issue](https://github.com/Lombiq/DotNest-Support/issues) to request a feature or the report a problem.
- [Join our Discord community](https://discord.gg/VbWp4HvcJB) for in-depth discussions with other DotNest users and our crew.
- See the [DotNest knowledge base](https://dotnest.com/knowledge-base/) to learn more about DotNest.
